# Typefaces

Both families are published under the SIL Open Font License 1.1
(https://openfontlicense.org), which permits bundling them with a site as
long as they are not sold on their own. The files are the latin-subset woff2
builds Google Fonts serves, fetched on 2026-09-15; they are named in
`export.py`'s allow-list, this note is not.

| File | Family | Cut | Source |
|---|---|---|---|

| `Newsreader-400.woff2` | Newsreader, © Production Type | regular 400 | https://fonts.google.com/specimen/Newsreader |
| `Newsreader-600.woff2` | Newsreader | semibold 600 | as above |
| `Newsreader-400i.woff2` | Newsreader | italic 400 | as above |

Fixed cuts of Newsreader rather than the variable file: the variable roman and
italic together were 280 KB, these three are 71 KB.
